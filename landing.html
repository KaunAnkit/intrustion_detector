Features

Everything you need for perimeter security

A self-hosted surveillance stack combining computer vision, AI, and a browser dashboard.

Real-Time Person Detection

YOLO11x model detects people in every live camera frame with a configurable confidence threshold (default 50%).

Custom Perimeter Drawing

Draw a freeform boundary line directly over the live video stream. Choose which side is the danger zone — left or right.

Intrusion Confirmation

A person must stay in the danger zone for at least 1 second before an intrusion is confirmed, eliminating false positives.

Automatic Image Capture

On confirmed intrusion, a cropped image of the intruder is saved instantly to disk with a timestamped filename.

Face Recognition

InsightFace buffalo_l extracts face embeddings. Cosine similarity matching identifies known individuals from your enrolled library.

Live MJPEG Dashboard

Browser-based dashboard streams live video with bounding-box overlays and perimeter visualization at up to 30 FPS.

Intrusion Log with Search

Every event is stored in SQLite with timestamp, capture, and recognition result. Search and filter by name, date, or status.

Webhook Alarm Integration

Sends a POST request to a configurable alarm URL on every confirmed intrusion for external integrations and hardware triggers.

Pipeline

How It Works

From raw camera frames to identified intruder in under a second.

1

Camera Capture

A dedicated daemon thread reads webcam frames at ~100 FPS via OpenCV and stores the latest frame in a thread-safe buffer.

2

YOLO11 Person Detection

Every 0.1 seconds, the analysis thread runs YOLO11x inference on the latest frame and extracts bounding boxes for all detected people above the confidence threshold.

3

Foot-Point Perimeter Check

The foot point (center-bottom of each bounding box) is tested against the user-defined polyline boundary. Points are normalized (0-1) for resolution independence.

4

Track Management and Confirmation

People are tracked across frames using Manhattan-distance matching. A person must remain in the danger zone for 1 continuous second before the intrusion is confirmed, preventing false alerts.

5

Capture and Embed

On confirmation, the intruder's crop is saved as a JPEG. InsightFace extracts a 512-d face embedding and stores it as a .npy file alongside the image.

6

Lazy Face Recognition

When you open the logs page, stored embeddings are compared against your enrolled face library using cosine similarity. Results above 55% are named; others are marked Unknown. Results are cached in SQLite.

7

Alarm and Dashboard Update

The dashboard status switches to INTRUSION. An optional webhook POST is sent to any configured alarm endpoint for hardware or third-party integrations.

API Reference

REST endpoints

All routes are served by the local FastAPI instance at http://localhost:8000.

Method Endpoint Description
GET / Main dashboard — live feed, status, intrusions today
GET /settings Settings page — draw and save the perimeter boundary
GET /logs Intrusion log page with search and filter controls
GET /video_feed MJPEG stream with overlay and perimeter visualization
GET /api/settings/frame Single JPEG snapshot of the current camera frame
GET /api/perimeter Return saved perimeter points and danger side
POST /api/perimeter Save a new perimeter (JSON body: points[], danger_side)
DELETE /api/perimeter Clear the saved perimeter and revert to default
GET /api/logs JSON list of intrusion logs (supports query, filter, sort params)
GET /captures/{image} Serve a captured intruder image by filename
GET /intrusion/status Current intrusion status value and timestamp
POST /intrusion/status Update intrusion status from an external alarm board
